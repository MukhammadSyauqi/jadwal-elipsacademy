Kebijakan Pembagian Role Sistem (PRD Poin 4)

Hierarki Hak Akses: Superadmin vs Admin Cabang

Role superadmin memegang kendali penuh lintas cabang (Buduran & Candi), mencakup penambahan akun staf, konfigurasi database, kontrol data master program kursus, dan penyelesaian konflik global. Sementara role admin didedikasikan untuk penugasan operasional spesifik per cabang guna menjaga integritas jadwal harian tanpa izin merombak struktur organisasi master.

Integritas & Keamanan Akun Laravel 11 (PRD Poin 6)

Enkripsi Password, Unique Key, & Audit Trail

Kolom email dijamin unik melalui Unique Constraint MySQL InnoDB untuk mencegah duplikasi identitas. Password diamankan secara mutlak menggunakan hashing satu arah (Hash::make()) tanpa pernah disimpan dalam plain text. Penonaktifan akun staf dilakukan secara virtual tanpa menghapus log historis untuk memelihara rekam jejak penjadwalan.
